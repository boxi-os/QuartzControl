A folder with an `index.md` becomes a page that stands for the folder — this one is the
example. The navigation on the left shows its title; clicking it unfolds the folder, and its
first entry, “Overview”, opens exactly this page.

A folder **without** an `index.md` gets an automatic listing page from Quartz. Both are fine;
with a file of your own you decide what it says.
