Ein Ordner mit einer `index.md` wird zu einer Seite, die den Ordner vertritt — diese hier ist
das Beispiel. In der Navigation links steht ihr Titel; ein Klick darauf klappt den Ordner auf, und
sein erster Eintrag, „Übersicht“, öffnet genau diese Seite.

Ein Ordner **ohne** `index.md` bekommt von Quartz eine automatische Übersichtsseite. Beides ist
richtig; mit einer eigenen Datei entscheidest du, was darauf steht.
