The navigation sorts by the numeric prefix in the file name: `1-first-steps.md` comes before
`2-folders-and-pages.md`. The number never shows in the title — that comes from the `title`
field.

| File                       | Title in the navigation |
| -------------------------- | ----------------------- |
| `1-first-steps.md`         | First steps             |
| `2-folders-and-pages.md`   | Folders and pages       |

If you would rather work without prefixes, set `navOrder` at the top of a note, or switch the
navigation to alphabetical sorting.
